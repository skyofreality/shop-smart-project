# Shop Smart - ML Learning Project

This repository is a learning project for practicing machine learning concepts on an e-commerce style dataset.

## Project Goal
Predict whether a session ends in a purchase (`Revenue`) using user behavior and session features.

## What I Practiced
- Basic data exploration with pandas
- Feature preparation (numerical + categorical)
- Building a preprocessing + model pipeline in scikit-learn
- Training a Decision Tree classifier
- Evaluating with F1 score, classification report, and confusion matrix
- Basic hyperparameter tuning with GridSearchCV

## Files in This Repository
- `shop_smart_ecommerce.csv` - dataset used in the analysis
- `shop_smart.ipynb` - EDA + baseline modeling workflow
- `shop_smart1.ipynb` - modeling workflow with preprocessing and hyperparameter tuning

## Tech Stack
- Python
- pandas
- numpy
- scikit-learn
- Jupyter Notebook

## How to Run
1. Create and activate a Python virtual environment.
2. Install dependencies:
   ```bash
   pip install pandas numpy scikit-learn jupyter
   ```
3. Open notebooks:
   ```bash
   jupyter notebook
   ```
4. Run cells in order.

## Learning Note
This project is for learning and experimentation, so the focus is on understanding concepts and workflow rather than production-level optimization.
